# 帮助与反馈 / Support

遇到导入、阅读、购买恢复或 AI 服务问题，请写信至 [luosilent@gmail.com](mailto:luosilent@gmail.com)。为帮助定位，可附上 App 版本、iOS 版本、设备型号和复现步骤；请不要发送 API Key、私人文章全文或付款卡信息。

## 常见问题

**我的笔记在哪里？** 笔记和高亮默认保存在设备上，可在“手记”及文章的“学习记录”中查看。当前没有跨设备云同步。

**为什么 AI 无法生成？** Apple 设备端模型需要兼容硬件、系统和可用模型。远程 AI 需要你自行配置有效的 HTTPS 服务与 API Key；服务限制或费用由提供方决定。

**如何恢复永久版？** 在 App 的购买页面使用“恢复购买”，并确认使用原购买时的 Apple 账号。若未恢复，请提供 App 版本、系统版本和非敏感的错误描述联系我们。

---

For help with imports, reading, restoring purchases, or AI configuration, email [luosilent@gmail.com](mailto:luosilent@gmail.com). Include the app and iOS versions, device model, and steps to reproduce where helpful. Do not send API keys, full private documents, or payment card details.

**Where are my notes?** Notes and highlights are stored on your device. Find them in Notes or an article's learning records. Cross-device cloud sync is not available.

**Why is AI unavailable?** Apple's on-device model requires compatible hardware, system support, and an available model. Remote AI requires your own valid HTTPS endpoint and API key. Provider limits and charges depend on that provider.

**How do I restore lifetime access?** Use Restore Purchases on the purchase screen with the Apple account used for the original purchase. If it fails, email us the app and system versions and a non-sensitive error description.
